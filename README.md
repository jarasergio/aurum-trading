# Aurum Trading

Algorithmic Multi-Asset Trading Platform

## Overview

Aurum Trading is a modular algorithmic trading platform
developed with Python and modern web technologies.

The platform is designed to support multiple financial
instruments, including:

- XAU/USD (Gold)
- EUR/USD
- NASDAQ
- Other configurable trading instruments

## Architecture

- Backend: Python + FastAPI
- Frontend: React + TypeScript
- Database: PostgreSQL
- Market analysis: pandas + NumPy
- Testing: pytest
- Code quality: Ruff
- Version control: Git + GitHub

## Main Components

- Market data management
- Trading strategies
- Risk management
- Backtesting
- Virtual execution
- Broker integration
- Web dashboard
- Trading statistics

## Development Principles

- Modular architecture
- Reproducible backtesting
- Independent strategies and brokers
- Secure credential management
- Simulation before live execution
- Automated testing

## Trading Safety

Live trading is disabled by default.

Historical performance does not guarantee future results.
